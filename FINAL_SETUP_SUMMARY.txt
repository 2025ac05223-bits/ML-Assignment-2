HOW TO USE - QUICK START
================================================================================

1. LAUNCH STREAMLIT APP (Local Development):

   Option A - Batch Script (Easiest):
     > run_app.bat

   Option B - PowerShell:
     > .\run_app.ps1

   Option C - Manual:
     > python -m streamlit run streamlit_app.py

   Access: http://localhost:8501

2. MAKE CODE CHANGES (Version Control):

   Check changes:
     git status
     git diff

   Stage changes:
     git add -A

   Commit:
     git commit -m "Update model performance"

   View history:
     git log --oneline

3. PUSH TO GITHUB (When Ready):

   Step 1: Create repository on GitHub
     - Go to github.com
     - Create new empty repository
     - Copy repository URL

   Step 2: Update local remote
     git remote set-url origin https://github.com/USERNAME/repo.git

   Step 3: Push code
     git branch -M main
     git push -u origin main

   Step 4: Authenticate
     - Use Personal Access Token (HTTPS) OR
     - Use SSH Key OR
     - Use Windows Credential Manager
     - GitHub login window will appear

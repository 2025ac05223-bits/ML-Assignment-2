NEXT STEPS - CONNECTING TO REMOTE REPOSITORY
================================================================================

When Ready to Push to GitHub/GitLab:

Step 1: Create Repository
  - Go to GitHub (github.com) or GitLab (gitlab.com)
  - Create new repository (leave empty, no README)
  - Copy repository URL

Step 2: Add Remote
  git remote add origin https://github.com/username/repo-name.git
  OR for SSH:
  git remote add origin git@github.com:username/repo-name.git

Step 3: Verify Remote
  git remote -v

Step 4: Push Code
  git branch -M main              # Rename branch to main (if needed)
  git push -u origin main         # Push to remote

Step 5: Authentication
  A login window will appear - Choose authentication method:
  - HTTPS: Enter personal access token
  - SSH: Use SSH key authentication
  - Windows: Use built-in Git Credential Manager

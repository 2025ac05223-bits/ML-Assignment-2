================================================================================
TROUBLESHOOTING
================================================================================

If Deployment Fails:
  1. Check Streamlit Cloud logs
  2. Verify requirements.txt has all packages
  3. Ensure streamlit_app.py is the main file
  4. Check for file path issues
  5. Verify GitHub repository is public

If App Crashes:
  1. Check Streamlit Cloud logs
  2. Look for missing imports or packages
  3. Verify data file paths
  4. Check for hardcoded paths
  5. Test locally first: run_app.bat

If App is Slow:
  1. First deployment is slower
  2. Model training on startup takes time
  3. Caching improves subsequent runs
  4. Acceptable performance after warmup

If Authentication Fails:
  1. Verify GitHub authorization
  2. Check account permissions
  3. Re-authorize Streamlit with GitHub
  4. Ensure repository is accessible

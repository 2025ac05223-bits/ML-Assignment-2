================================================================================
COMMIT MESSAGE GUIDE
================================================================================

Good Format:
  git commit -m "Add new feature: model performance visualization"

Bad Format:
  git commit -m "fixed stuff"
  git commit -m "update"

Types to Use:
  feat:    New feature
  fix:     Bug fix
  docs:    Documentation
  refactor: Code cleanup
  test:    Test changes

Example:
  git commit -m "feat: Add Breast Cancer dataset migration"

================================================================================
COMMON WORKFLOWS
================================================================================

Starting New Work:
  git checkout -b feature/my-feature    # Create branch
  # ... make changes ...
  git add -A                             # Stage changes
  git commit -m "description"            # Commit
  git push -u origin feature/my-feature  # Push branch

Viewing Changes:
  git diff               # Unstaged changes
  git diff --staged      # Staged changes
  git log -p             # Commit details with changes

Undoing Changes:
  git checkout -- <file> # Discard changes in file
  git reset HEAD <file>  # Unstage file
  git revert <commit>    # Undo a commit

IF YOU GET STUCK
================================================================================

Problem: I made changes but don't know what changed
  Solution: git status, git diff, git log

Problem: I want to see the commit history
  Solution: git log --oneline, git log --graph

Problem: I committed something wrong
  Solution: git revert <commit-hash>, git reset --soft HEAD~1

Problem: I need to sync with remote
  Solution: git pull, git fetch

Problem: I forgot what my branch is for
  Solution: git branch, git log origin/main..HEAD

Get Help:
  git --help                # General help
  git <command> --help      # Command-specific help

================================================================================
USEFUL ALIASES (Optional Setup)
================================================================================

Add to ~/.gitconfig to save typing:

  git config --global alias.st status
  git config --global alias.co checkout
  git config --global alias.br branch
  git config --global alias.ci commit
  git config --global alias.unstage 'reset HEAD --'
  git config --global alias.last 'log -1 HEAD'
  git config --global alias.visual 'log --graph --oneline --all'

Then use:
  git st          # Instead of git status
  git co -b feat  # Instead of git checkout -b feat
  git visual      # Instead of git log --graph --oneline --all
